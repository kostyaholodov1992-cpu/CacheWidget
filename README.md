# Cache Cleaner Widget

Виджет одной кнопкой очищает кэш всех пользовательских приложений.
Работает через Accessibility-сервис, без root.

## Сборка APK через GitHub Actions (без Android Studio)

1. Создайте репозиторий на github.com (Public).
2. Загрузите в него ВСЕ файлы и папки из этого архива (в корень репозитория).
3. Подождите: сборка запустится сама, займёт 5–10 минут.
4. Вкладка Actions → зелёный запуск → внизу раздел Artifacts → скачайте CacheWidget-debug.
5. Внутри архива — готовый APK.

## Установка на Samsung

1. Установите APK (разрешите установку из неизвестных источников).
2. Настройки → Приложения → Cache Cleaner → меню ⋮ → «Разрешить ограниченные настройки»
   (нужно на Android 13+, иначе сервис доступности не включится).
3. Откройте приложение Cache Cleaner → кнопка «Открыть настройки доступности»
   → включите «Cache Cleaner».
4. Удерживайте палец на пустом месте рабочего стола → Виджеты → Cache Cleaner
   → перетащите кнопку «Очистить кэш» на экран.

## Как работает

Тап по виджету запускает сервис: он перебирает все пользовательские приложения,
для каждого открывает страницу настроек → «Хранилище» → «Очистить кэш».
Системные приложения пропускаются. По окончании возвращается на рабочий стол.
Во время работы не трогайте телефон.
